===============================
How to use 0-add_integer
===============================

Import the function:

>>> add_integer = __import__('0-add_integer').add_integer

Test integers:

>>> add_integer(1, 2)
3

>>> add_integer(100, -2)
98

Test default value:

>>> add_integer(2)
100

Test floats:

>>> add_integer(100.3, -2)
98

Test invalid b:

>>> add_integer(4, "School")
Traceback (most recent call last):
...
TypeError: b must be an integer

Test invalid a:

>>> add_integer(None)
Traceback (most recent call last):
...
TypeError: a must be an integer

Test float conversion:

>>> add_integer(1.9, 2.9)
3

Test both floats:

>>> add_integer(-1.5, 3.5)
2

Test boolean values:

>>> add_integer(True, False)
1
