The ``0-add_integer`` module
=============================

Import the function:

    >>> add_integer = __import__('0-add_integer').add_integer

Basic addition of two integers:

    >>> add_integer(1, 2)
    3

Addition with a negative number:

    >>> add_integer(100, -2)
    98

Using the default value of b:

    >>> add_integer(2)
    100

Floats are cast to integers before adding:

    >>> add_integer(100.3, -2)
    98

Both arguments as floats:

    >>> add_integer(2.9, 3.9)
    5

Two negative integers:

    >>> add_integer(-1, -1)
    -2

Passing a non-number as the second argument raises a TypeError:

    >>> add_integer(4, "School")
    Traceback (most recent call last):
    TypeError: b must be an integer

Passing a non-number as the first argument raises a TypeError:

    >>> add_integer(None)
    Traceback (most recent call last):
    TypeError: a must be an integer
