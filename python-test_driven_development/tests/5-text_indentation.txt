The ``5-text_indentation`` module
===================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

A simple sentence ending with a period:

    >>> text_indentation("Hello.")
    Hello.
    <BLANKLINE>

A sentence with multiple delimiters:

    >>> text_indentation("Hi: how are you? I am fine.")
    Hi:
    <BLANKLINE>
    how are you?
    <BLANKLINE>
    I am fine.
    <BLANKLINE>

Extra spaces around delimiters are stripped:

    >>> text_indentation("   Hello.   World?   ")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>

Text with no delimiters prints as a single line, no trailing newline:

    >>> text_indentation("Hello world")
    Hello world

An empty string prints nothing:

    >>> text_indentation("")

text must be a string:

    >>> text_indentation(12)

text can't be None:

    >>> text_indentation(None)
    Traceback (most recent call last):
    TypeError: text must be a string

text can't be a list:

    >>> text_indentation(["Hello."])
    Traceback (most recent call last):
    TypeError: text must be a string
